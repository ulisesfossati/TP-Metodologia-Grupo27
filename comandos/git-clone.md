# Git clone

El comando `git clone` descarga una copia completa de un repositorio remoto en nuestra computadora. Incluye los archivos, el historial de commits y la información de las ramas.

## Sintaxis

```bash
git clone URL_DEL_REPOSITORIO
```

## Ejemplo

```bash
git clone https://github.com/usuario/tp-git.git
```

También se puede elegir el nombre de la carpeta:

```bash
git clone https://github.com/usuario/tp-git.git trabajo-git
```

## Cuándo se utiliza

Se utiliza cuando queremos comenzar a trabajar con un repositorio que ya existe en GitHub u otro servicio remoto.
