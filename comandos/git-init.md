# Git init

El comando `git init` crea un repositorio Git nuevo dentro de una carpeta. Al ejecutarlo, Git genera una carpeta oculta llamada `.git`, donde guarda el historial, las ramas y la configuración del repositorio.

## Sintaxis

```bash
git init
```

## Ejemplo

```bash
mkdir tp-git
cd tp-git
git init
```

Después de ejecutarlo, la carpeta queda preparada para comenzar a registrar cambios con Git.

## Cuándo se utiliza

Se utiliza cuando empezamos un proyecto local que todavía no está siendo controlado por Git.
